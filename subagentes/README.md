# Subagentes — Móvil

Índice de definiciones de agentes destinadas a OpenCode y específicas de Móvil. Los archivos están en `.opencode/agents/`; su descubrimiento o ejecución en cualquier runtime no está validado. La Constitución propia prevalece.

- [Arquitecto Móvil](../.opencode/agents/movil-arquitecto.md) — Arquitectura de UI, estado, navegación, ciclo de vida y adaptadores.
- [Revisor de accesibilidad Móvil](../.opencode/agents/movil-revisor-accesibilidad.md) — Semántica, foco, contraste, escalabilidad de texto y accesibilidad futura.
- [Revisor SDD Móvil](../.opencode/agents/movil-revisor-sdd.md) — Alineación entre Constitución propia, AGENTS, spec, plan y task de Móvil.
- [Revisor de seguridad Móvil](../.opencode/agents/movil-revisor-seguridad.md) — Permisos del dispositivo, almacenamiento local y manejo de secretos de cliente.
- [Revisor de integración Móvil](../.opencode/agents/movil-revisor-integracion.md) — Adaptadores remotos, conectividad, compatibilidad y separación cliente-servidor.

**Compatibilidad:** las definiciones enlazadas están en formato OpenCode bajo `.opencode/agents/`. No se declaran instaladas, descubiertas o funcionales en Codex. No se ejecutan agentes en esta fase.
